# 📰 News Blogging Website (PHP & MySQL)

## 📘 Project Overview

This project is a **dynamic news/blogging web application** built using **PHP and MySQL**.
It allows **admins and users** to create, manage, and publish blog posts with full **CRUD (Create, Read, Update, Delete)** functionality.

The platform provides a simple and efficient way to manage content and users, making it suitable for a basic **content management system (CMS)**.


## 🚀 Key Features

### 👨‍💼 Admin Features

* Add, update, and delete users
* Manage all blog posts
* Full control over content and users
* View and manage categories (if implemented)


### 👤 User Features

* Create blog posts
* Edit their own posts
* Delete posts
* View all posts


### 📝 General Features

* Full **CRUD operations** for posts and users
* Organized blog/news display
* User authentication (login/logout system)
* Role-based access (Admin & User)
* Clean and simple UI
* Add image upload for posts
* Add search and filtering
* Pagination for posts


## 🧠 Concepts Practiced

* PHP backend development
* MySQL database design
* CRUD operations
* Authentication and authorization
* Role-based access control
* Server-side form handling


## ⚙️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Server:** XAMPP / WAMP


## 🚀 How to Run the Project

1. Install **XAMPP/WAMP**
2. Place project folder in:

   ```
   htdocs/
   ```
3. Start **Apache** and **MySQL**
4. Import the database file into **phpMyAdmin**
5. Update database connection in `config.php`
6. Open in browser:

   ```
   http://localhost/your-project-folder
   ```
